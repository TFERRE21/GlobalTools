Gerador de Meta Tags

Monte um bloco básico de metadados HTML para o título, a descrição e a URL canônica de uma página.

O HTML gerado aparecerá aqui.

O que são meta tags?

Metadados ajudam navegadores e mecanismos de busca a compreender informações básicas de uma página. O título identifica o documento; a meta description pode ser usada como resumo nos resultados, embora o mecanismo de pesquisa possa escolher outro trecho.

Como usar

  1. Informe um título descritivo na primeira linha.
  2. Escreva uma descrição fiel ao conteúdo na segunda linha.
  3. Informe a URL canônica absoluta na terceira linha.
  4. Gere as tags e revise o HTML antes de publicar.

Boas práticas

Evite repetir palavras-chave artificialmente, criar descrições enganosas ou usar a mesma descrição em todas as páginas. A URL canônica deve apontar para a versão preferencial real da página.

Limitações

O gerador cria apenas tags básicas. Ele não garante indexação nem posições nos resultados. Dados estruturados, Open Graph e diretivas de indexação podem precisar de configuração adicional.

Perguntas frequentes

A meta description garante o texto exibido no Google?

Não. O Google pode gerar um trecho com base no conteúdo da página e na consulta.

Posso copiar as mesmas tags em todas as páginas?

Não é recomendado. Cada página deve ter metadados que representem seu próprio conteúdo.
