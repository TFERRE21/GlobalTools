O que é CSV?

CSV (valores separados por delimitadores) é um formato de texto usado para trocar dados entre planilhas e sistemas. Cada linha costuma representar um registro e os campos são separados por vírgulas, ponto e vírgula ou outro delimitador acordado.

Como usar

  1. Cole os dados com uma linha por registro.
  2. Confira se a primeira linha contém cabeçalhos quando necessário.
  3. Clique em “Visualizar CSV” e verifique o alinhamento das colunas.

Delimitadores e formatação

Arquivos exportados em português podem utilizar ponto e vírgula como separador, especialmente quando a vírgula é usada como separador decimal. A ferramenta mostra uma prévia simples; confira o delimitador do arquivo original.

Limitações

Esta prévia não é um editor de planilhas nem um validador completo de CSV. Campos que contêm vírgulas entre aspas, aspas escapadas ou quebras de linha internas exigem um parser CSV completo para interpretação fiel.

Privacidade

O conteúdo colado é processado no navegador. Ainda assim, não compartilhe dados pessoais, financeiros ou empresariais confidenciais em páginas públicas sem avaliar os riscos.

Perguntas frequentes

Por que algumas colunas aparecem incorretas?

O delimitador pode ser diferente de vírgula ou o arquivo pode conter campos entre aspas. Confira a estrutura antes de usar os dados.
