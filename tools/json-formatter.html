Formatador JSON

Organize dados JSON com indentação e valide a sintaxe antes de utilizá-los em uma aplicação.

O JSON formatado aparecerá aqui.

O que é JSON?

JSON (JavaScript Object Notation) é um formato de texto utilizado para representar dados estruturados e trocar informações entre aplicações. Objetos usam chaves e valores; arrays armazenam listas ordenadas. Strings devem usar aspas duplas e os valores podem ser strings, números, booleanos, null, objetos ou arrays.

Como usar o formatador

  1. Cole um documento JSON no campo da ferramenta.
  2. Clique em “Formatar JSON”.
  3. Se houver erro, revise a mensagem e confira aspas, vírgulas, colchetes e chaves.

Exemplo válido

{"produto":"Caderno","preco":12.5,"disponivel":true}

Um formatador organiza a apresentação, mas não altera a finalidade nem confirma que os dados estão corretos para a sua aplicação.

Erros comuns

JSON não aceita comentários no formato padrão, exige aspas duplas nas chaves e strings e não permite vírgula sobrando após o último item de um objeto ou array. Valores como NaN e undefined também não são valores JSON válidos.

Privacidade e segurança

Evite colar chaves de API, tokens de acesso, senhas ou dados pessoais. Mesmo quando o processamento ocorre no navegador, extensões e o ambiente do dispositivo podem influenciar a segurança das informações.

Perguntas frequentes

Formatar JSON corrige todos os erros?

Não. A ferramenta pode identificar erros de sintaxe, mas a estrutura ainda pode estar semanticamente incorreta para a aplicação de destino.

JSON e JavaScript são a mesma coisa?

Não. JSON é um formato de dados com regras mais restritas do que a sintaxe geral de JavaScript.
