Conversor de HEX para RGB

Converta um código hexadecimal de cor para os valores RGB usados em CSS, design e desenvolvimento de interfaces.

Os valores RGB aparecerão aqui.

O que significam HEX e RGB?

HEX representa os canais de cor com números hexadecimais. RGB descreve a intensidade de vermelho, verde e azul, normalmente com valores de 0 a 255 para cada canal.

Como usar

  1. Digite uma cor HEX de seis dígitos, com ou sem o sinal #, conforme o formato aceito.
  2. Execute a conversão.
  3. Copie os valores RGB para a ferramenta ou folha de estilo de destino.

Exemplo

A cor #FFFFFF corresponde a RGB(255, 255, 255), que representa branco. #000000 corresponde a RGB(0, 0, 0), que representa preto.

Limitações

RGB e HEX descrevem valores de cor, mas não garantem contraste adequado, fidelidade de impressão ou aparência idêntica em todos os dispositivos. Verifique acessibilidade e contraste no contexto real.
