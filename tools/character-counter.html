Sobre o Contador de Caracteres

Conte caracteres com e sem espaços de forma rápida e gratuita. A ferramenta Oolivo ajuda você a revisar textos sem precisar instalar programas.

Como usar

Digite ou cole seu texto no campo acima e clique em “Contar caracteres” para ver o resultado. Confira o resultado antes de usá-lo em documentos importantes.

Perguntas frequentes

É grátis? Sim, esta ferramenta pode ser usada gratuitamente.

Preciso criar uma conta? Não é necessário criar conta para usar esta ferramenta.
