Conversor de Bases Numéricas

Converta um número para binário, decimal e hexadecimal informando a base em que o número original está escrito.

As conversões aparecerão aqui.

O que é uma base numérica?

A base define quantos símbolos são usados para representar valores. O sistema decimal usa dez símbolos (0 a 9), o binário usa dois (0 e 1) e o hexadecimal usa dezesseis (0 a 9 e A a F).

Como usar

  1. Digite o número e, depois de um espaço, a base de origem.
  2. Para hexadecimal, use a base 16; para binário, use 2; para decimal, use 10.
  3. Execute a conversão e confira as representações retornadas.

Exemplo

O valor hexadecimal FF representa 255 em decimal e 11111111 em binário. Para testar, informe “FF 16”.

Limitações

Esta ferramenta é voltada a números inteiros representáveis pelo JavaScript. Confira o sinal, a base informada e os limites de precisão quando trabalhar com valores muito grandes.

Onde isso é útil?

Bases numéricas são usadas em programação, endereços de memória, códigos de cores, protocolos e eletrônica digital. A conversão ajuda a interpretar valores em diferentes contextos.
