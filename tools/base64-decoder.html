Decodificador Base64

Converta uma sequência Base64 de volta para texto quando a entrada representar texto válido.

O resultado aparecerá aqui.

O que é Base64?

Base64 representa bytes usando um conjunto de caracteres de texto. É útil para transportar dados em contextos que esperam texto, mas aumenta o tamanho da representação e não protege o conteúdo por criptografia.

Como usar

  1. Cole uma sequência Base64 válida.
  2. Clique em “Decodificar texto”.
  3. Confira o resultado e confirme que ele corresponde ao tipo de dado esperado.

Limitações

Esta ferramenta é voltada a conteúdo que possa ser decodificado como texto. Dados binários, texto com outra codificação ou Base64 incompleto podem produzir erros ou caracteres inesperados.

Privacidade

O processamento é realizado no navegador. Mesmo assim, não cole tokens, senhas, chaves de API ou dados pessoais sensíveis em ferramentas públicas.

Perguntas frequentes

Base64 é criptografia?

Não. Qualquer pessoa que tenha a sequência pode decodificá-la. Não use Base64 para proteger segredos.

Por que a saída fica ilegível?

O conteúdo pode representar bytes binários ou ter sido codificado com um conjunto de caracteres diferente.
