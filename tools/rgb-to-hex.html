Conversor de RGB para HEX

Transforme três canais RGB em um código hexadecimal de cor para usar em CSS e projetos visuais.

O código HEX aparecerá aqui.

Como funciona RGB?

RGB representa uma cor pela intensidade dos canais vermelho, verde e azul. Cada canal normalmente varia de 0 a 255. A combinação dos três valores define a cor resultante em telas e sistemas digitais compatíveis.

Como usar

  1. Digite três valores entre 0 e 255, na ordem vermelho, verde e azul.
  2. Separe os valores com vírgulas ou espaços.
  3. Execute a conversão e copie o código HEX gerado.

Exemplos

RGB(255, 255, 255) corresponde a #FFFFFF (branco). RGB(0, 0, 0) corresponde a #000000 (preto).

Limitações

O código HEX representa valores de cor, mas não garante contraste adequado nem aparência idêntica em diferentes telas. Confira a acessibilidade da combinação de texto e fundo no contexto em que será usada.
