Gerador de Código QR

Crie um código QR a partir de um texto ou URL para facilitar o acesso por câmeras de celulares.

O código QR aparecerá aqui.

O que é um código QR?

Um código QR é uma imagem bidimensional que pode armazenar texto, endereços web e outros dados. A câmera ou um leitor compatível interpreta o padrão e pode oferecer uma ação com base no conteúdo.

Como usar

  1. Digite o texto ou URL que deseja codificar.
  2. Clique em “Gerar código QR”.
  3. Leia o código com um segundo dispositivo para confirmar que o conteúdo está correto antes de imprimir ou compartilhar.

Serviço externo

A geração da imagem utiliza um serviço externo de QR. O texto ou endereço informado é enviado ao fornecedor para produzir a imagem; não inclua senhas, tokens, links privados ou informações confidenciais.

Boas práticas

Se o QR aponta para um site, use um endereço confiável e teste o destino antes de imprimir. Um código QR não torna um link seguro; usuários devem verificar o domínio antes de inserir dados ou realizar pagamentos.

Limitações

A legibilidade depende do tamanho, contraste, qualidade de impressão e quantidade de dados codificados. Para uso profissional, teste o código em diferentes dispositivos e condições de iluminação.
