Conversor de Binário para Decimal e Hexadecimal

Digite um número formado apenas por 0 e 1 para consultar seu valor decimal e hexadecimal.

O resultado aparecerá aqui.

O que é o sistema binário?

O sistema binário usa apenas os dígitos 0 e 1. Cada posição representa uma potência de 2. Computadores utilizam bits e bytes para representar números, texto e outros dados.

Como usar

  1. Digite um número binário usando apenas 0 e 1.
  2. Clique em “Converter número”.
  3. Confira os valores decimal e hexadecimal.

Exemplo

O binário 101101 equivale a 45 em decimal e 2D em hexadecimal.

Limitações

A ferramenta converte inteiros não negativos e usa a capacidade de BigInt do navegador. Ela não realiza operações aritméticas entre dois números; para esse uso, utilize uma calculadora binária que suporte operações.
