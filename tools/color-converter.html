HEX e RGB: qual é a diferença?

HEX representa os canais de cor usando dígitos hexadecimais. RGB descreve a intensidade de vermelho, verde e azul, normalmente com valores de 0 a 255 para cada canal.

Como usar

  1. Digite um código HEX válido, como #336699.
  2. Clique em “Converter cor”.
  3. Copie os valores RGB para o seu CSS ou editor de design.

Exemplos de cores

#FFFFFF corresponde a RGB(255, 255, 255), branco. #000000 corresponde a RGB(0, 0, 0), preto. #FF0000 corresponde a RGB(255, 0, 0), vermelho.

Limitações

Valores HEX e RGB descrevem cores digitais, mas não garantem aparência idêntica em todas as telas ou impressoras. Confira contraste e acessibilidade na interface final.
