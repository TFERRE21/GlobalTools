Conversor de CSV para JSON

Converta uma tabela CSV em uma lista de objetos JSON usando a primeira linha como cabeçalho.

O resultado aparecerá aqui.

O que é CSV?

CSV é um formato de texto tabular em que cada linha representa um registro. A primeira linha geralmente contém os nomes das colunas; as linhas seguintes contêm os valores.

Como usar

  1. Cole os dados CSV, incluindo a linha de cabeçalho.
  2. Confira se o separador é vírgula e se os campos estão alinhados.
  3. Converta e revise o JSON antes de importá-lo em outro sistema.

Campos com vírgulas e aspas

Um CSV válido pode colocar campos entre aspas quando eles contêm vírgulas ou quebras de linha. Esta ferramenta reconhece campos entre aspas e aspas duplicadas, mas a importação final deve ser conferida com o sistema que receberá os dados.

Limitações

Todos os valores convertidos são tratados como texto; a ferramenta não infere automaticamente números, datas ou valores booleanos. Cabeçalhos vazios ou repetidos podem precisar de correção manual.

Privacidade

O processamento ocorre no navegador. Ainda assim, evite colar dados pessoais ou empresariais confidenciais em ferramentas públicas.
