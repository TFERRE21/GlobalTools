Analisador de URL

Insira um endereço completo para consultar seus componentes principais e entender como a URL está estruturada.

Os componentes aparecerão aqui.

Componentes de uma URL

Uma URL pode incluir protocolo (como https), host ou domínio, porta, caminho, parâmetros de consulta e fragmento. Cada parte pode influenciar a forma como o navegador acessa um recurso.

Como usar

  1. Cole a URL completa, incluindo o protocolo.
  2. Execute a análise.
  3. Revise os componentes para identificar parâmetros ou caminhos inesperados.

Parâmetros de consulta

A parte após o ponto de interrogação costuma carregar pares chave-valor, como origem de campanha ou filtros. Evite incluir dados pessoais, senhas ou tokens nesses parâmetros, pois URLs podem aparecer em históricos, logs e cabeçalhos de referência.

Limitações

A análise estrutural não verifica se o domínio é confiável, se a página existe ou se o destino é seguro. Não abra links suspeitos apenas porque a URL foi analisada.

Veja também o analisador de parâmetros de URL e o criador de URLs com UTM.
