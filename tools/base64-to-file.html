O que é Base64?

Base64 representa bytes usando caracteres de texto. A codificação é usada em integrações e transporte de dados, mas não criptografa nem protege o conteúdo.

Como usar

  1. Cole a sequência Base64 sem cabeçalhos desnecessários, salvo se fizer parte do formato de entrada esperado.
  2. Informe um nome de arquivo que ajude a identificar o conteúdo.
  3. Clique em “Baixar arquivo” e verifique o arquivo com um aplicativo apropriado.

Escolha o nome e o formato

O nome fornecido determina o nome do download, mas não converte o conteúdo para outro formato. Se os bytes forem de uma imagem, PDF ou arquivo compactado, use a extensão correspondente apenas quando souber qual é o formato real.

Segurança

Não baixe nem abra arquivos codificados de fontes desconhecidas. Conteúdo Base64 pode representar qualquer tipo de arquivo, inclusive dados maliciosos. O processamento no navegador não garante que o arquivo seja seguro.

Limitações

O decodificador espera Base64 válido. Sequências incompletas ou caracteres inválidos podem causar erro. Arquivos grandes também podem consumir memória do navegador.
