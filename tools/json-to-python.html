JSON para Python

Transforme um JSON válido em uma representação inicial de estruturas de dados do Python.

O resultado aparecerá aqui.

JSON e Python

JSON e Python compartilham conceitos como objetos e listas, mas usam sintaxes diferentes. Em Python, objetos JSON normalmente correspondem a dicionários e arrays a listas; booleanos e valores nulos também têm nomes diferentes.

Como usar

  1. Cole dados JSON válidos.
  2. Clique para converter.
  3. Confira strings, números, listas e objetos aninhados.

Cuidados ao usar o resultado

Uma representação de dados não é necessariamente um programa completo. Ao inserir dados em código Python, valide a entrada e evite executar conteúdo desconhecido como código. Para carregar JSON, a biblioteca padrão json costuma ser uma opção simples.

Limitações

O resultado é uma representação inicial. Verifique tipos especiais, codificação, campos opcionais e a estrutura dos objetos antes de incorporá-lo ao projeto.
