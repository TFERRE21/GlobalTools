Conversor de Texto para Binário

Converta texto em uma sequência binária para visualizar a representação numérica dos caracteres.

A sequência binária aparecerá aqui.

O que é binário?

O sistema binário utiliza apenas os dígitos 0 e 1. Computadores representam dados como sequências de bits, agrupados em unidades como bytes. A codificação usada pelo texto determina como os caracteres são transformados em bytes.

Como usar

  1. Digite ou cole o texto.
  2. Clique em “Converter para binário”.
  3. Copie a sequência se precisar utilizá-la em um exercício ou exemplo.

Exemplo

Na codificação ASCII, a letra A corresponde ao valor decimal 65 e à sequência binária de 8 bits 01000001. Caracteres acentuados e emojis podem exigir vários bytes em UTF-8, por isso não são necessariamente representados por um único grupo de oito bits.

Limitações

Esta ferramenta mostra o valor de cada ponto de código em grupos binários de pelo menos oito bits; isso não equivale a uma codificação UTF-8 completa para todos os caracteres Unicode. Use um conversor baseado em bytes UTF-8 quando precisar de compatibilidade exata com arquivos ou protocolos.
