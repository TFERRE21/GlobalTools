Conversor de Binário para Texto

Converta grupos binários em caracteres para entender como valores binários podem representar texto.

Como usar

  1. Informe grupos de oito bits separados por espaços.
  2. Clique em “Converter para texto”.
  3. Confira o texto resultante.

Exemplo

Os grupos 01001000 01101001 representam “Hi” em ASCII. Cada grupo corresponde a um valor numérico entre 0 e 255.

Limitações

Esta versão converte cada byte em um caractere de byte simples. Caracteres acentuados e outros símbolos Unicode podem exigir decodificação UTF-8 de sequências de vários bytes.

Privacidade

O processamento ocorre no navegador. Evite converter ou compartilhar dados binários que contenham informações confidenciais.
