# GlobalTools

GlobalTools is a free, global collection of fast online utilities.

## Vision
Build a large, SEO-friendly platform of browser-based tools for PDF, images, text, developers, generators and everyday tasks.

## Stack
- Static HTML
- CSS
- Vanilla JavaScript
- Browser-first processing where possible
- SEO-ready individual tool pages

## Initial categories
- PDF Tools
- Image Tools
- Text Tools
- Developer Tools
- Generators
- Converters

All tools are intended to be free and easy to use.
